Notes in Paymanshu's own words for the voice and terminal agent: views, interests
and background that aren't on the resume. One topic per file, written in first
person, with `## ` headings for sub-topics.

The agent indexes every `*.md` here (files starting with `_` are skipped)
together with the blog posts and /cooking projects, and only uses a section when
a visitor's question clearly matches it (see `knowledge_lookup` in
`agent/resume_context.py`). This repo is public, so only add what you'd say on
the site anyway.
